# Gem Puzzle

Пятнашки в браузере. Как должна выглядеть и вести себя игра, написано в `TASK.md`. Это продуктовое описание. Способ сборки и технические ограничения лежат в агентах и их скиллах в `.cursor/`.

Игра собирается по задачам доски GitHub. Все задачи вместе равны готовому продукту.

## Один чат

Человек пишет в текущий чат, какую задачу с доски взять. Агент читает её, предлагает описание и план и ждёт. После согласия или правок роли initializer, coder и evaluator работают в этом же чате. В конце человек открывает и вливает pull request.

Другой чат для роли не нужен.

## Роли

- `.cursor/agents/initializer.md` — читает задачу и согласует план
- `.cursor/agents/coder.md` — делает согласованный объём
- `.cursor/agents/evaluator.md` — проверяет объём этой задачи

## Доска

Задачи помечены `board:backlog`, `board:in-progress`, `board:in-review`, `board:done`.

```bash
gh issue list --label board:backlog --limit 30
```

Ветка `feat/cursor_work_2` хранит уже собранную игру как образец поведения. Её не переписывают и не вливают в задачу.
